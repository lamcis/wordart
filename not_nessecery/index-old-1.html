Archive.org 和 WikiArt 的 API 不允许浏览器直接调用（CORS限制）。配置代理后可解决。
免费代理示例：https://corsproxy.io/?url=
另一个选项：https://api.allorigins.win/raw?url=
自建Node代理：http://localhost:3001/proxy?url=
