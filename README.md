# 聚艺（Word Art丨词语-艺术）

## 发行说明

**聚艺（Word Art丨词语-艺术）——借艺术学习词语，经词语发现世界。**

聚艺是一款免费、无广告的轻量级多感官联合语言学习工具——用高质量的艺术、技术、人文图像学习语言。在这里，你可以认识单词，而不再是死记硬背地学习单词。

在聚艺发挥想象，与人类的历史热烈相拥。把单词作为支点，让世界的明眸撬动你。学习语言，欣赏艺术，看见世界；走向语言，走向艺术，走向世界。



## 核心特点

#### 多感官学习体验
同时对于文字学习型、图像学习型和听觉学习型人群友好。通过文字、图像、听觉、动脑思考、做笔记多方位同时记忆；利用播放音频、筛选图像、记忆图像、编写说明的实践活动，实现主动式、综合性学习。

#### 低学习成本
页面简单，重点突出，无需教程，打开即用。

#### 多语言与跨学科学习

- 复制、编辑、迁移、备份

- 随时导出与导入学习进度

# 使用与分享说明

除了学习单词，每个人都可以使用聚艺分享自己从某个领域出发，直观、简单、充满个人特色的认识世界的视角。

## 应用场景

- 艺术家 / 人文传播者：构建“个人博物馆”
- 教育者：制作主题词库
- 普通用户：记录与分享认知世界的方式

你可以：
- 编写关键词库
- 标注“合格”图像或添加图片 URL
- 编辑说明文字
- 导出批注，然后分享给任何人、分享到任何地方。

---

## 使用方法

### 1. 创建词库
制作一个关键词文本文件（`.txt`）：
- 每行一个词

如需文章结构（标题 + 正文），使用 `.json` 格式。

---

### 2. 导入词库
导入后，为每个词：
- 标注图像
- 或手动添加图片 URL
- 编写说明

---

### 3. 导出成果
点击右上角：

**设置 → 导出反馈**

即可导出你的学习与标注成果。

---

### 4. 更新词库
- 点击“加载单词”导入新词库
- 不影响已有图片与标注

---

### 5. 恢复数据
如标注丢失：
- 点击“加载反馈”
- 导入之前导出的文件即可恢复

---

## 分享方式

你可以将词库分享至任何平台：

- 作为学习资源
- 作为个人知识体系
- 作为图像与认知集合

让更多人通过你的视角，看见世界。
